# Portafolio Personal — Kleyver Urbina

Portafolio web personal de **Kleyver Urbina** (Desarrollador Full Stack). Landing page estática desarrollada en Astro 7 y Tailwind CSS v4, animada con GSAP y desplegada en GitHub Pages.

🌐 **Sitio en Vivo:** [https://kleyverx.github.io/portfoliokley/](https://kleyverx.github.io/portfoliokley/)

---

## 🛠️ Tecnologías Principales

- **Framework:** [Astro 7](https://astro.build/)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animaciones & 3D:** GSAP (ScrollTrigger), Lottie, Spline
- **Internacionalización:** i18n cliente (es / en / fr)
- **Contacto:** Integración directa con EmailJS

---

## 🚀 Comandos

```bash
# Instalación de dependencias
npm install

# Servidor de desarrollo (localhost:4321)
npm run dev

# Build estático para producción (salida en ./dist/)
npm run build

# Previsualización del build local
npm run preview
```
