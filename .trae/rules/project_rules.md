Estructura base del portafolio:

Mantener las secciones: Inicio, Sobre mí, Proyectos, Contacto.

Permitir agregar proyectos destacados con imágenes, descripción y tecnologías usadas.

Respetar una jerarquía visual clara y coherente.

Estilo visual:

Basarse en componentes de React Bits y Shadcn UI siguiendo las guías oficiales.

Aplicar colores armónicos, tipografía moderna y uso coherente de íconos.

Diseñar con enfoque minimalista, fluido y atractivo para clientes.

Animaciones y transiciones:

Usar GSAP para animaciones de entrada/salida y efectos de scroll.

Usar Lottie para un preloader animado y microinteracciones (ej. íconos animados).

Integrar Lenis para un desplazamiento suave y natural.

Desarrollo técnico:

Los componentes deben ser modulares, reutilizables y bien documentados.

Estilos con CSS o módulos CSS, sin Tailwind ni Styled Components.

Optimizar imágenes y animaciones para tiempos de carga rápidos.

Experiencia de usuario (UX):

El portafolio debe ser 100% responsive.

La navegación debe ser intuitiva, con feedback visual en cada interacción (hover, click, scroll).

El formulario de contacto debe ser funcional y con validación de entrada.

Cumplimiento MCP y contexto:

Cualquier cambio o sugerencia debe respetar el contexto del usuario almacenado.

El agente debe consultar y usar las reglas anteriores antes de modificar contenido o código.

Los resultados deben reflejar tanto el contexto técnico (frameworks, librerías) como los objetivos de diseño del usuario.
